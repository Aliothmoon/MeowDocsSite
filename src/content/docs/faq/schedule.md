定时任务能不能准时跑起来，取决于三件事：MaaMeow 本身正常、系统没有杀掉后台、锁屏时能自动解锁。下面按这个顺序排查。

:::caution[凌晨四点]
明日方舟每天 04:00 刷新数据，正在运行的任务会被打断。长时间挂机（比如刷肉鸽）请在 04:00 之后加一个定时任务，把任务重新拉起来。
:::

## 定时任务没有执行

先看触发日志：点击右上角的圆形箭头，再点右上角第二个设置按钮，里面有触发日志。

- **日志里什么都没有**：任务根本没有触发，按下面三步排查。
- **日志里有执行记录**：记录下方会写报错原因，可以带着它向群友求助。

### 三步排查

1. **前台亮屏**：设一个 3 分钟后的定时任务，把 MaaMeow 留在前台观察。能正常执行说明 MaaMeow 本身没问题；不能执行说明 MaaMeow 异常，请到群里求助。
2. **后台亮屏**：上一步通过后，再设一个 3 分钟后的定时任务，切到后台观察。能正常执行说明后台保活正常；不能执行说明 MaaMeow 被系统杀掉了，请检查是否打开了后台高耗电和自启动权限，见[前置权限与设置](/faq/setup/#前置权限与设置)。
3. **锁屏**：锁屏后无法唤醒，大概率是上一步的权限没开，或者没有配置解锁方式。

## 锁屏状态下唤醒

打开「设置 → 其他设置」，有三种解锁方式可选：

| 方式 | 要求 |
| --- | --- |
| 滑动解锁 | 手机不设密码，只保留滑动解锁。 |
| 手势录制（强烈推荐） | 录一遍你正常输入密码解锁的过程。录制时必须输入密码，不能用指纹、人脸等生物识别，否则需要重新录制。 |
| PIN | 填入手机密码。手机上只能保留人脸，不能有指纹。 |

手势录制主要是为了规避指纹解锁界面挡住密码输入的情况。

<details class="faq">
<summary>小米 / 红米：到了时间不解锁、不启动</summary>

适用于澎湃 OS 1、2、3 和 MIUI。系统没有授予 MaaMeow 锁屏和后台弹窗权限时，会拦截定时唤醒和锁屏自启动。

进入「系统设置 → 应用设置 → 应用管理 → MaaMeow → 权限管理」，把下面两项都设为允许：

- 锁屏显示
- 后台弹出界面

</details>

## 熄屏挂机

保活能力强的手机，开好后台高耗电并锁住后台之后，可以真正熄屏在后台跑。

其他手机可以用 MaaMeow 自带的熄屏挂机：在后台任务运行界面点右下角的三个点，选择「熄屏挂机」。它只是把屏幕变黑省电，并不是系统的熄屏或锁屏，既能省电防误触，又不会因为系统锁屏导致任务中断或截图黑屏。

<details class="faq">
<summary>可以锁屏刷图，或者清理后台吗？</summary>

- 所有机型都不建议划掉 MaaMeow 的后台卡片，否则系统杀掉进程后无法靠自启动唤醒。
- 已经解决后台管控问题的机型可以锁屏刷，16 GB 这样的大内存机型一般可以；爱杀后台或内存小的机型不行。总体不建议锁屏刷。

</details>
