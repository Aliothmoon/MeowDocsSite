本指南只讨论 **后台模式**，目标是 15 分钟内让你掌握 MaaMeow 的基础操作。

:::note[本站定位]
MaaMeow 是 MAA 的安卓端。这里只整理 MaaMeow 特有的常见问题和踩坑记录，各任务功能的完整说明请查阅 [MAA 官方文档](https://docs.maa.plus/zh-cn/manual/introduction/startup.html)。
:::

## 工作原理

MaaMeow 基于图像识别技术，在后台虚拟显示器中无界面运行。不注入、不修改游戏数据，通常不会导致封号。

:::caution[使用前请检查]
- **异形 UI** 会导致界面识别出错，请在游戏内把异形屏适配拉到 0。
- **护眼模式**、**省电模式**、**游戏模式** 和 **自定义字体** 会改变画面或分辨率，有概率让 MAA 无法识别，请关闭。
- **定时任务要在锁屏状态下启动**，需要先配置解锁方式，见[定时任务](/faq/schedule/#锁屏状态下唤醒)。
:::

<details class="faq">
<summary>前台模式能用吗？</summary>

能用，但不推荐。群里反馈过的问题包括：

- 编辑任务闪退。
- 点悬浮球后任务停掉。
- 分辨率和触控位置对不上。

后台模式开全屏可以接近前台体验，只是触控反馈可能稍差一点。除非只是临时跑一下，或者某些场景必须看着画面，否则强烈不建议使用前台模式。

</details>

<details class="faq">
<summary>云手机能用吗？</summary>

云手机的情况更复杂一些：

- 不建议优先用 root 授权 Shizuku，能走无线调试就先走无线调试。
- 系统版本太低，或者分辨率比例不是常规的 16:9，兼容性会比较差。
- 实在不行就退回前台模式，或者换一个云手机方案。

真机后台模式优先，云手机先看兼容性再做决定。

</details>

## 下载与更新

### 下载 MaaMeow

- **交流群群文件**（推荐）：群文件里的 MaaMeow 安装包就是最新版本。[点击加入交流群](https://join.maameow.com)。
- **下载文件群**：QQ 群 915168210。
- **GitHub**：在 [MAA-Meow 的 Releases](https://github.com/Aliothmoon/MAA-Meow/releases) 下载 apk。GitHub 服务器大多在海外，不一定能直连。

装好之后还要配置 Shizuku 才能使用，见[安装与授权](/faq/setup/)。

### 更新 App 与资源

![更新管理界面](../../../assets/faq/image1.jpg)

设置页的「更新管理」可以分别检查 App 本体和 MAA 资源的更新，下载源可选 GitHub 或 Mirror酱。

进入 App 时如果弹出资源更新提示，点更新即可。旧资源也能用，但遇到新活动可能出问题，建议保持最新。

:::tip[下载源怎么选]
能访问 GitHub 的话直接选 GitHub，记得让代理放行 MaaMeow。下载速度只有几 KB 时换成 Mirror酱，它是付费的国内高速下载服务。
:::

<details class="faq">
<summary>每次打开都有公告弹窗</summary>

公告强烈建议看完。不想再看到的话，停留五秒后勾选左下角的「下次公告更新前不再提醒」，再点确认。

</details>

## 关于提问的正确方式

<details class="faq">
<summary>任务失败了，怎样提问才容易得到解答？</summary>

1. 点击右上角齿轮进入设置，打开 **调试模式**。
2. 复现一遍问题并录屏。必须在打开调试模式之后复现。
3. 在设置的日志栏里点「导出日志压缩包」。
4. 把视频和日志一起发出来。

不开调试模式会导致日志信息太少，无法准确定位问题。

![设置中的调试模式](../../../assets/faq/image2.jpg)

</details>

## 编辑配置与编辑任务

<details class="faq">
<summary>编辑任务</summary>

点击「编辑任务」可以自由输入以更改任务名称。点击「新增任务」可以添加一个任务模块。

**修改完必须点确定**，否则无法点击任务模块修改任务设置。

</details>

<details class="faq">
<summary>编辑配置</summary>

可以自由组合任务顺序。任务从上到下依次执行，长按任务模块可以拖动更换顺序。

:::caution
「开始唤醒」如果不在置顶，会导致无法启动游戏而报错。
:::

</details>
